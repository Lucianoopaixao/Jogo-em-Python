# 🎮 Royal Rush

Projeto desenvolvido como conclusão da disciplina de Introdução à Programação do curso de Sistemas de Informação no Centro de Informática da UFPE (CIn/UFPE).

## 👑 Sobre o jogo

**Royal Rush** é um game 2D desenvolvido em Python utilizando a biblioteca Pygame.

A proposta do jogo coloca dois jogadores competindo no mesmo teclado em um labirinto cheio de obstáculos:

* O **Rei Gelado** tenta capturar a **Princesa Jujuba**
* A princesa deve escapar enquanto atravessa o mapa

O jogo foi inspirado no universo de *Hora de Aventura*, trazendo uma experiência dinâmica e divertida.

## 🧩 Conceitos aplicados

Durante o desenvolvimento do projeto, foram utilizados conceitos fundamentais de programação, como:

* Estruturas condicionais e de repetição
* Listas, tuplas e dicionários
* Modularização com funções
* Programação Orientada a Objetos (POO)
* Testes e refinamentos contínuos

---

## 🏗️ Estrutura do projeto

O projeto foi desenvolvido seguindo uma estrutura modular baseada em POO, facilitando:

* Organização do código
* Reutilização de componentes
* Manutenção e expansão do jogo

---

## 📚 Aprendizados

O desenvolvimento do Royal Rush proporcionou aprendizados importantes, como:

* A importância do controle de versão desde o início do projeto
* O valor da divisão de tarefas e da colaboração em equipe
* A necessidade de testes constantes para garantir a jogabilidade
* O uso da Programação Orientada a Objetos na organização de projetos maiores
