🎮 Royal Rush – Projeto Acadêmico

Como conclusão da disciplina de Introdução à Programação no curso de Sistemas de Informação (CIn/UFPE), desenvolvi junto com minha equipe Ana Raquel, Lavínya Souza, Clarissa Honório, Marcos Silva e Jaiane Evilásio o Royal Rush, um game 2D em Python/Pygame.

👑 A proposta:
O Rei Gelado tenta capturar a Princesa Jujuba em um labirinto cheio de obstáculos. Dois jogadores competem no mesmo teclado, cada um com objetivos opostos — garantindo partidas dinâmicas e divertidas.

⚙️ Destaques técnicos:
	•	Desenvolvido em Python + Pygame
	•	Estrutura modular com POO
	•	Ambientação inspirada em Hora de Aventura
	•	Trabalho colaborativo com GitHub

📚 Conceitos aplicados:
	•	Estruturas condicionais e de repetição
	•	Listas, tuplas e dicionários
	•	Modularização com funções
	•	Programação Orientada a Objetos
	•	Testes e refinamentos contínuos

📖 Aprendizados:
	•	Importância do controle de versão desde o início
	•	Valor da divisão de tarefas e da colaboração em equipe
	•	Necessidade de testes constantes para garantir jogabilidade
	•	Uso da POO na organização de projetos mais complexos
